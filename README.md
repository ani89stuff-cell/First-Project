# Book-O-Phile

A community book review platform — Phase A landing page UI with static mock data.

## Stack

- [Vite](https://vite.dev/) + React + TypeScript
- [Tailwind CSS](https://tailwindcss.com/) v4

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

## Scripts

| Command        | Description              |
| -------------- | ------------------------ |
| `npm run dev`  | Start development server |
| `npm run build`| Production build         |
| `npm run preview` | Preview production build |

## Phase A scope

- Landing page with mock data only
- Book name autocomplete (simulated)
- Search & discover with filter tabs
- Review form with success toast (no persistence)

Out of scope: database, authentication, API calls, routing.
